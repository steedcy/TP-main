# P1 统一代理通信阶段验收记录

- 阶段状态：用户验收通过
- 实施日期：2026-10-13
- 接口基线：`设备仿真通信契约-P0.md` / `设备仿真通信契约-P0.json`

## 本阶段交付

1. 新增设备独立Bearer令牌轮换、摘要校验和AES-GCM加密存储。令牌只在轮换响应中返回一次；用户会话令牌不能通过设备上报认证。连接测试、绑定和命令下发均由统一HTTP适配器发起。
2. 将连接测试改为真实健康握手，校验协议版本、nonce、设备编号、仿真类型、在线/工作状态、位置、能力列表和时间戳；代理创建提交后发送绑定请求。
3. 新增统一报告接口 `/device-api/v1/agents/{agentCode}/report`。状态、承接响应和执行反馈均通过同一服务校验、持久化状态并推进任务；旧路由只做兼容转换。
4. 新增附录B六类消息的统一分发接口 `/internal/v1/device-agent/messages`，下行命令写入 `device_commands`，按代理、命令、类型和尝试次数去重；上行反馈按幂等键记录摘要，重复内容不重复推进，复用幂等键但改变内容会被拒绝。
5. 任务执行器通过设备消息网关发送承接/执行命令；人工终止会发出 `TASK_CANCEL`，任务冻结后迟到的承接响应和执行反馈只记录并忽略。原 `SimulatedAgentResponder` 固定成功实现已删除。
6. 新增 Flyway V13：设备令牌摘要/密文/签发时间、代理最新业务状态快照、命令记录表和上报去重表。

主要代码位于 `backend/src/main/java/com/airport/ai/device/`、`backend/src/main/java/com/airport/ai/config/` 和 `backend/src/main/java/com/airport/ai/task/`；配置及启动要求更新在项目 `README.md`。

## 验证结果

- 后端 `mvn -q clean test`：15项测试通过，0失败、0错误、0跳过。
- 覆盖设备凭据签发/匹配、设备令牌过滤器、健康握手字段、健康/绑定/命令的本机HTTP往返、命令幂等与内容冲突、运动安全字段拦截、报告重复及冲突处理、离线/恢复状态转移、附录B六类内部消息分发。
- 真实应用启动与Flyway执行未完成：本机PostgreSQL端口可连通，但项目默认用户名 `admin` 的密码被本机数据库拒绝；仓库未提供其他连接配置。本次启动在建立数据库连接前退出，V13没有应用到数据库。需要用有效的 `DB_USERNAME` / `DB_PASSWORD` 环境变量复验部署迁移。

用户已确认P1验收通过；P2在独立对话中继续。V13数据库迁移仍待提供有效数据库凭据后另行执行。
