# F023 分层防御分支与底图部署条件（V2.4）

2026-11-08，BL-008；业务原文和95编号不变。

1. R07 / TC-071.S1：缺失或无效坐标的状态只能出现在图外列表，不能被错误定位。验收分别执行真实档案HTTP缺X/缺Y拒绝及持久不变、实际快照控制器对上游空坐标的保留契约、生产前端消费合成快照（缺X/缺Y/空串/负数/越界以及有效0/最大边界）后的列表与地图检查。三层证据必须分别标注；禁止宣称合成状态是合法持久档案或真实设备端到端。当前真实离线/恢复仍走实际心跳、事件与数据库。
2. R09 / TC-070.S3：当前固定底图未更换时，检查资源真实宽高、实际像素坐标与R08缩放换算、界面重标提示及只读入口。不同像素尺寸/裁剪范围的实际部署必须由实施方重标全部设备，再重新执行R08/R09；不能引用本轮结果为未来换图验收证明。本轮不要求人为更换未变更的固定底图。
