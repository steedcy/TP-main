# 测试用例 V2 补充检查 V2.1

本表增加原用例内可能被一次成功路径掩盖的独立分支。原 TC-001～TC-095 的编号、步骤、预期和历史结果不覆盖；AC 编号只用于附加检查。每项记录实际输入、预期、实际、时间、环境版本和证据。任一适用 AC 失败，其关联原用例不得判 P；不能执行则关联用例仍为 NT（若另有实测失败则 F）。

| AC-008 | TC-046 / F014、NF015 | 监督服务返回无法确定、超时、不可用；再提供硬校验失败版本。 | 前三项安全转人工或合格基线，平台可用；硬失败不能进入监督或设备派发。 |
| AC-009 | TC-051 / F016 | 三个受控候选组分别仅改变能力匹配度、区域距离、当前负载；首选拒绝后下一个接受。 | 每层排序依据和拒绝原因有事件，接受前无业务指令，最终设备正确。 |
| AC-010 | TC-052 / F016 | 同时争抢同一代理；另建无候选和全拒绝任务。 | 无双重占用；两种失败原因分别可追溯，按异常恢复流程处理。 |

| AC-013 | TC-055 / F017 | 成功但完成条件不满足、首次失败重试成功、重试仍失败、静默超时四个独立任务。 | 逐任务核对同号/重试次数、最终步骤与任务状态、异常/恢复事件；成功 HTTP 不代替业务完成。 |

| AC-017 | TC-072 / F024 | 操作员目标和模拟测量事件分别触发超规样本 80×55×35 cm、35 kg；柜台可填/缺省。 | 记录阈值 158 cm/32 kg、来源和比较值，展示/上报/机器人引导由正确物理渠道完成，缺柜台按原文补充或安全处置。 |
