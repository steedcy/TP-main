## 二、历史缺陷与阻断项全量闭环核验

1. **DEF-S3-032（身份脱敏与隐私保护）：关闭。**

   - 包含真实身份证件号的事件办理说明直接被 HTTP 400 拦截拒绝，不生成任务实例。
2. **DEF-S3-119（正常行李不生成引导步骤）：关闭。**
   - 任务 1204 及后续正常行李实测确认：任务状态直接为 `COMPLETED`，`currentPlanVersionId` 为 null，计划版本表及任务步骤分配表中步骤数严格为 0，内存与持久化记录严格一致。
3. **DEF-S3-120（超规阈值与计算属性覆盖对照）：关闭。**
   - 阈值等于（158cm / 23kg）、略超、默认 23kg、正数边界等 23 组标量测试全部通过，覆盖计算字段与来源一致性。
4. **DEF-S3-121（仿真控制台真实 UI 路由与操作）：关闭。**
   - 真实 Edge 浏览器 headless 实测成功访问 `/simulators` 路由，CONFIG_ADMIN 与 OPERATOR 角色均可查看“模拟行李测量事件触发”卡片，通过表单成功提交正常/超规测量事件，页面实时展示标签及状态。
5. **DEF-S3-122（测量设备重试与备用切换）：关闭。**
   - 扫描器单次失败后自动重试成功；重试仍失败切换候选扫描器 `G183_F024_SCAN2` 成功。
6. **DEF-S3-123（两扫描器均离线无虚构测量）：关闭。**
   - 两台扫描器同时离线时，记录 `CAPABILITY_GAP`，不虚构测量数据，任务安全转待人工处理。
7. **DEF-S3-124（两移动机器人离线无虚假引导闭环）：关闭。**
   - 移动资源完全缺失时，完成前 3 步（测量、告警、航显），第 4 步标记无法执行并正确记录 `GUIDANCE_UNCOVERED`，不虚报闭环。
8. **DEF-S3-125（缺字段测量反馈及柜台回退）：关闭。**
   - 缺少尺寸、重量或超规标记的 3 组测量反馈均被拒绝，阻断不完整执行。
9. **NT-S3-004、NT-S3-005：关闭。**
   - 仿真测量事件自动触发、柜台可选/必填、办理说明页面与四渠道风险分支均在当前版本实测覆盖。
