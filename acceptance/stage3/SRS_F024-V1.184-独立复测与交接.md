## 缺陷裁决

- **DEF-S3-032：关闭。** 目标文本任务 1200 将虚构身份替换为 `[PROTECTED_IDENTITY]`；任务、事件和模型请求无原 canary。事件办理说明 canary 直接 HTTP 400，未创建任务，隔离 SQL 查询和模型日志均无 canary。
- **DEF-S3-119：保持 F。** SQL 直接显示任务 1159 `COMPLETED`、`current_plan_version_id=1132`，计划含测量、告警、信息展示、导航四步；仅第 1 步完成，后续分配为 SKIPPED。该行为仍违反 R03 原文。
- **DEF-S3-120：关闭。** 计算字段覆盖对照保持实测尺寸、重量、阈值与来源一致。
- **DEF-S3-121：NT。** CONFIG_ADMIN 合法事件 API 返回 200，非法空请求返回 400；但 `/simulators` 真实路由、操作员 UI 及权限按钮仍未被浏览器观察，故不关闭完整缺陷。
- **DEF-S3-122：关闭。** 测量设备离线后检测、备用设备重分派、恢复事件和后续四步完成均有协议/SQL 证据。
- **DEF-S3-123：关闭。** 两扫描器离线时无虚构测量，记录 `CAPABILITY_GAP`/无在线候选并转人工。
- **DEF-S3-124：关闭。** 两移动资源离线时仍完成可用测量、告警和信息展示，标记 `GUIDANCE_UNCOVERED`，不报告虚假闭环。
- **DEF-S3-125：关闭。** 缺尺寸、缺重量、缺 `isOversize` 的三条 SUCCESS 反馈均不能完成测量步骤或后续业务。
