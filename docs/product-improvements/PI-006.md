# PI-006：协同任务看板、矢量室内地图编辑器与 POI 拓扑升级

- **状态**：已合入 `main`（提交 `ea81d6e` ～ `7b9b2f2`）
- **版本**：V1.5 基线前序改进

## 1. 改进原因

原有二维态势底图以静态像素坐标为主，缺乏交互式区域/走廊/点位编辑能力及任务执行过程的可视化回放；在三类典型场景中需要进一步提升空间拓扑语义与动态规划直观性。

## 2. 主要改动

1. **协同任务看板与地图气泡（`ea81d6e`、`b78c577`、`77c8075`）**：
   - 新增协同任务看板，展示设备态势、路径拓扑、步骤回放及指令/反馈地图语音气泡。
   - 修复看板设备代理快照字段解析与任务详情设备名称展示。
2. **室内矢量地图编辑器（`47392d0`、`649e66a`）**：
   - 集成 Leaflet 与 Leaflet-Geoman 室内矢量地图编辑器，支持区域、走廊与设施点位的交互编辑及 GeoJSON 导入导出。
   - 补齐操作员视角下的 POI/区域/走廊管理与中文可读性展示。
3. **航站楼语义对齐与坐标校准（`326bdaf`、`fa40ce8`、`7f8de62`、`7b9b2f2`）**：
   - 对齐隔离区/值机区/走廊语义并补充商铺与设施点位，校准默认测量表单与柜台标签。
   - 航班变更场景支持自定义旅客起点坐标 `(390, 3070)` 及动态 `CAP_ESCORT` 陪同规划。
