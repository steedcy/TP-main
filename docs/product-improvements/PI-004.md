| 实测问题 | 当前行为 |
| --- | --- |
| 航变输入要求延误，基线却发布登机口变更示例 | 预置模板绑定当前结构化变更类型、说明、新时间和登机口，发布、展示及通知使用同一份业务内容。自定义模板继续保留显式文案。演示日期随提交当天生成。 |
| 行李导航目标未标定，模板提前导航 | 仿真地标表补齐演示会合点、值机岛和 B01 专柜。行李模板先测量、再告警、展示和专柜导航，正常分支测量后结束。坐标是本机虚构演示位置。 |
| 测量事件被重复测量，事件模式不受设备支持 | 新事件追加不可变测量记录。后续测量步骤引用已登记样本并标注来源，使用条件更新防止并发重复推进。旧事件兼容其任务内保留的样本。事件样本不满足步骤条件时转人工核对。 |
| 陪同提示只有“轮椅陪同”，无会合反馈 | 提示包含协助类型、起点和目的地。新增到会合点的机器人导航步骤，实际到达后返回地点与设备编码，随后由同一机器人陪同至目的地。 |
| 正常行李页面仍显示超规缴费说明 | 正常或待判定结果隐藏专柜及缴费说明；结果页展示事件复用来源。历史陪同任务缺少会合回报时如实提示。 |
| 仿真页面测量事件默认阈值与行李仪不同 | 页面显式传入 158 cm、32 kg 及附录 F 来源。直接调用事件 API 继续支持原默认阈值和自定义阈值。 |
