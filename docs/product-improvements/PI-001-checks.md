# PI-001 产品改进验证范围

原 SRS/TC 编号仅标识受影响接口和邻接行为。下列检查用于产品演示与改进验证。

| 追踪 | 原执行观察 | 本次生效补充与需验证的断言 |
| --- | --- | --- |
| SRS_F003.R01 / TC-008.S1 | 接入地址、凭据标识必填；新增后手工准备进程 | 仿真体两字段可留空，由系统生成本机地址及令牌引用；真实设备仍必填。新增事务自动生成独立令牌，密钥缺失须回滚，普通查询不包含明文、摘要或密文。编码、区域、坐标、上报周期等原校验不变。 |
| SRS_F003.R02/R03 / TC-009.S1 | 未测试档案由管理员点击连接测试，通过后允许创建代理 | 新建仿真体自动启动异步连接测试；身份、类型和状态校验通过后才创建/绑定代理；以本轮真实心跳确认接入完成，失败保存原因并允许重试。保留人工连接测试入口。 |
| SRS_F003.R08 / TC-009.S2/S3 | 失败原因及凭据掩码回归 | 启动失败、外部端口占用、远程不可管理、连接失败、绑定/回调失败均不得显示接入完成。轮换只在当次响应展示明文；旧令牌立即失效。 |
| SRS_F004.R01/R08 / TC-011.S1、TC-012.S3 | 一设备一启用代理，生命周期留痕 | 自动接入/轮换/重试复用既有代理，不增加重复代理；归档代理不可恢复。令牌签发/轮换及既有代理生命周期保留审计。进行中任务禁止重启/轮换，排队重启时旧代理退出调度候选。 |
| SRS_F005、SRS_F028（必要邻接） | 真实状态上报、角色权限、隐私 | 四种仿真驱动均按已有协议上报真实心跳；操作员不可轮换令牌/重启进程；继承能力仍须通过能力测试后才能启用。 |
